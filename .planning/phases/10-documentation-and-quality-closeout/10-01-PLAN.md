# Plan 10-01: Document TLS, Client Authentication, and the Bind Policy

<objective>
更新安全与运维文档，使其准确描述 v0.4.0 的信任边界：TLS 终止、客户端认证（mTLS/bearer）、非回环暴露规则、授权审计，以及从旧版本的迁移路径（COMPAT-02）。
</objective>

<threat_model>
**ASVS Level:** 1 · **Block on:** high

| ID | Threat | Severity | Mitigation in this plan |
|----|--------|----------|-------------------------|
| T-10-01 | 文档仍宣称"无 TLS/无认证"，导致运维误配 | HIGH | 重写威胁模型与限制文档 |
| T-10-02 | 文档暗示令牌可内联进 YAML | HIGH | 明确令牌来自 env 或文件 |
| T-10-03 | 迁移说明缺失，升级后客户端被规则拒绝 | MEDIUM | 每个文档给出迁移路径 |
</threat_model>

<must_haves>
- `THREAT-MODEL.md`：信任边界含 TLS/auth；暴露决策为"opt-in + TLS + 客户端认证"；新增审计控制与新的已知限制
- `docs/SESSION-AND-LIMITS.md`：中英双语更新限制表、传输安全、客户端认证、授权审计、迁移
- `RELEASE-NOTES.md`：新增 `## v0.4.0` 小节（特性、兼容性、迁移）
- `docs/WINDOWS-SERVICE.md`：TLS/auth 配置示例、退出码 3 的双重含义、`diagnose` 的 TLS 布尔
- 文档明确令牌来自 `SKF_TLS_TOKEN` 或 `token_file`，绝不内联 YAML
- 文档明确默认仍是明文回环，37 夹具不变
</must_haves>

<task id="10-01-01" type="execute">
  <name>威胁模型与 Windows 服务文档</name>
  <files>THREAT-MODEL.md, docs/WINDOWS-SERVICE.md</files>
  <read_first>
    - `THREAT-MODEL.md` 全文
    - `docs/WINDOWS-SERVICE.md` 全文
    - `.planning/phases/10-documentation-and-quality-closeout/10-RESEARCH.md`
  </read_first>
  <action>
    1. `THREAT-MODEL.md`：
       - 标题/首段改为 v0.4.0。
       - 信任边界表：WebSocket 监听器行改为"默认回环；非回环需 opt-in + TLS + 客户端认证"。
       - 新增 "Transport security (v0.4.0)" 小节：TLS 由 `rustls` + `ring` 提供，最低 TLS 1.2；`tls.cert_file`/`tls.key_file`；`client_auth: none|mtls|token`；`mtls` 用 `client_ca_file`；`token` 用 `SKF_TLS_TOKEN`/`token_file`（不内联）。
       - 重写 "Exposure decision"：不再是"无 TLS"，而是三项控制齐备才允许远程。
       - Controls 增加一条 "Authorization audit"：granted/denied/expired/device-unavailable 以结构化非敏感事件记录。
       - Known limitations：删除"No TLS or client authentication"；新增：令牌在无 TLS 时仅限回环；证书轮换为人工；无按客户端 ACL。
    2. `docs/WINDOWS-SERVICE.md`：
       - 新增 "TLS and client authentication" 小节，给出 `tls:` 配置示例（含 `client_auth: mtls` 与 `token` 两种）与证书来源说明。
       - 启动阶段/退出码小节：说明 exit code `3` 同时覆盖"绑定失败"与"暴露规则拒绝"。
       - 说明 `skf-service.exe diagnose --json` 输出 `tls_enabled`/`tls_cert_loaded` 布尔，且不含路径或密钥。
  </action>
  <acceptance_criteria>
    - `grep -c 'v0.4.0' THREAT-MODEL.md` 输出 `>= 1`
    - `grep -ci 'client authentication' THREAT-MODEL.md` 输出 `>= 1`
    - `grep -c 'client_ca_file' THREAT-MODEL.md` 输出 `>= 1`
    - `grep -c 'tls:' docs/WINDOWS-SERVICE.md` 输出 `>= 1`
    - `grep -c 'tls_cert_loaded' docs/WINDOWS-SERVICE.md` 输出 `>= 1`
    - `grep -c 'No TLS or client authentication' THREAT-MODEL.md` 输出 `0`
  </acceptance_criteria>
  <verify>`grep -ci 'client authentication' THREAT-MODEL.md && grep -c 'tls_cert_loaded' docs/WINDOWS-SERVICE.md`</verify>
</task>

       - 新增中文"传输安全与客户端认证"小节 + 英文对应小节：TLS 配置、三种模式、令牌来源（env/文件，不内联）、已认证身份（CN/token 类别）。
