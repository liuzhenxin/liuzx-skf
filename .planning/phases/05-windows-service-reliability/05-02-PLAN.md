# Plan 05-02: Install-Directory Permissions and Reliable Upgrade/Uninstall

<objective>
安装器对安装目录施加并校验限制性 ACL（SVC-03），安装/升级/卸载用轮询等待替代固定 sleep 以避免锁定文件与残留注册（SVC-04），并提供 Windows 人工验证脚本与文档。

依赖 05-01 的状态文件与阶段输出（`verify-service.ps1` 会断言 `status` 的 `stage`）。
</objective>

<threat_model>
**ASVS Level:** 1 · **Block on:** high

| ID | Threat | Severity | Mitigation in this plan |
|----|--------|----------|-------------------------|
| T-05-06 | 非管理员替换已加载的 exe/DLL（DLL 劫持/提权） | HIGH | `icacls /inheritance:r` 仅 SYSTEM/Administrators 可写，Users 仅 RX，并校验 |
| T-05-07 | 覆盖升级时旧进程仍持有文件，导致复制失败或半更新 | HIGH | 轮询等待 Stopped + exe 可独占打开（超时报错），替代 800ms sleep |
| T-05-08 | 卸载后残留服务注册或锁定目录 | MEDIUM | 卸载等待进程退出与注册移除；`Remove-Item` 失败不再静默 |
| T-05-09 | ACL 命令写错（例如仍继承可写权限） | MEDIUM | 设置后解析 `icacls` 输出并断言 Users 无 (F)/(M)/(W) |
</threat_model>

<must_haves>
- `install.ps1` 复制负载后执行 `icacls /inheritance:r`，授予 SYSTEM:F、Administrators:F、Users:RX，并校验 Users 无写权限
- `install.ps1`/`uninstall.ps1` 不再使用固定 `Start-Sleep` 作为等待；改为轮询 SCM Stopped 与 exe 独占可打开（30s 超时，超时报错）
- `uninstall.ps1` 的 `Remove-Item` 失败不静默
- 新增 `packaging/windows/verify-service.ps1`：install → status → 覆盖升级 → status → uninstall（断言无注册残留、目录已删）→ reinstall → uninstall
- 新增 `docs/WINDOWS-SERVICE.md`：退出码、状态文件 schema、安装/升级/卸载、ACL、人工验证步骤
- 现有 37 夹具与 `cargo test` 不受影响
</must_haves>

<task id="05-02-01" type="execute">
  <name>安装目录 ACL（设置 + 校验）</name>
  <files>packaging/windows/install.ps1</files>
  <read_first>
    - `packaging/windows/install.ps1` 全文
    - `.planning/phases/05-windows-service-reliability/05-CONTEXT.md` — D-11/D-12/D-13
    - `.planning/phases/05-windows-service-reliability/05-RESEARCH.md` §6
  </read_first>
  <action>
    在复制负载并确认 `$Exe` 存在之后、注册服务之前，新增：
    ```powershell
    Write-Host "==> Applying restrictive ACL to $InstallDir ..."
    $aclInherit = 'icacls "{0}" /inheritance:r /grant:r "SYSTEM:(OI)(CI)F" "Administrators:(OI)(CI)F" "Users:(OI)(CI)RX"' -f $InstallDir
    cmd /c $aclInherit | Out-Null
    if ($LASTEXITCODE -ne 0) { throw "icacls failed with exit code $LASTEXITCODE" }

    # Verify Users cannot write; a non-administrator must not be able to replace
    # the loaded executable or the vendor DLL.
    $usersLines = (icacls "$InstallDir") -split "`r?`n" | Where-Object { $_ -match 'Users' }
    if ($usersLines -match '\(F\)|\(M\)|\(W\)') {
        throw "install directory is still writable by Users: $usersLines"
    }
    ```
    注意：`icacls` 是外部命令，`/grant:r` 替换继承授权。`cmd /c` 用于避免 PowerShell 对参数的解析问题，也可直接用 `& icacls ...` 逐参传递。
    保持 `#requires -RunAsAdministrator`。
  </action>
  <acceptance_criteria>
    - `grep -c 'icacls' packaging/windows/install.ps1` 输出 `>= 2`
    - `grep -c '/inheritance:r' packaging/windows/install.ps1` 输出 `1`
    - `grep -c 'Users:(OI)(CI)RX' packaging/windows/install.ps1` 输出 `1`
    - `grep -c 'writable by Users' packaging/windows/install.ps1` 输出 `1`
  </acceptance_criteria>

<task id="05-02-02" type="execute">
  <name>升级/卸载的轮询等待与严格清理</name>
  <files>packaging/windows/install.ps1, packaging/windows/uninstall.ps1</files>
  <read_first>
    - `packaging/windows/install.ps1`、`packaging/windows/uninstall.ps1` 全文
    - `.planning/phases/05-windows-service-reliability/05-CONTEXT.md` — D-14/D-15
  </read_first>
  <action>
    1. 在 `install.ps1` 定义辅助函数：
       ```powershell
       function Wait-ServiceStoppedAndUnlocked {
           param([string]$ServiceName, [string]$ExePath, [int]$TimeoutSeconds = 30)
           $deadline = (Get-Date).AddSeconds($TimeoutSeconds)
           while ((Get-Date) -lt $deadline) {
               $svc = Get-Service -Name $ServiceName -ErrorAction SilentlyContinue
               $isStopped = (-not $svc) -or ($svc.Status -eq 'Stopped')
               $isUnlocked = $true
               if (Test-Path $ExePath) {
                   try {
                       $fs = [IO.File]::Open($ExePath, 'Open', 'ReadWrite', 'None')
                       $fs.Close()
                   } catch { $isUnlocked = $false }
               }
               if ($isStopped -and $isUnlocked) { return $true }
               Start-Sleep -Milliseconds 300
           }
           return $false
       }
       ```
    2. 用 `if (-not (Wait-ServiceStoppedAndUnlocked -ServiceName $ServiceName -ExePath $Exe)) { throw "..." }` 替换现有 `Start-Sleep -Milliseconds 800`，并在通过后再 `Remove-Item $InstallDir -Recurse -Force -ErrorAction Stop`（去掉 `SilentlyContinue`）。
    3. `uninstall.ps1` 做同样处理：删除注册后调用 `Wait-ServiceStoppedAndUnlocked`；`Remove-Item` 用 `-ErrorAction Stop` 并在失败时 `throw`。
    4. 保持幂等：目录不存在时不报错。
  </action>
  <acceptance_criteria>
    - `grep -c 'Milliseconds 800' packaging/windows/install.ps1` 输出 `0`（旧的固定 800ms 等待必须移除）
    - `grep -c 'Start-Sleep -Milliseconds 300' packaging/windows/install.ps1` 输出 `1`（仅存在于轮询辅助函数内）
    - `grep -c 'IO.File' packaging/windows/install.ps1` 输出 `>= 1`
    - `grep -c 'Wait-ServiceStoppedAndUnlocked' packaging/windows/install.ps1` 输出 `>= 2`（定义 + 调用）
    - `grep -c 'Wait-ServiceStoppedAndUnlocked' packaging/windows/uninstall.ps1` 输出 `>= 1`
    - `grep -c 'SilentlyContinue' packaging/windows/uninstall.ps1` 输出 `0`（服务查询的 SilentlyContinue 可保留；Remove-Item 不得再用）
    - `grep -c 'Remove-Item' packaging/windows/uninstall.ps1` 与 `-ErrorAction Stop` 同时出现
  </acceptance_criteria>
  <verify>`grep -c 'Wait-ServiceStoppedAndUnlocked' packaging/windows/install.ps1 packaging/windows/uninstall.ps1`</verify>

<task id="05-02-03" type="execute">
  <name>Windows 人工验证脚本</name>
  <files>packaging/windows/verify-service.ps1</files>
  <read_first>
    - `packaging/windows/install.ps1` / `uninstall.ps1`（本计划产出）
    - `src/win_service.rs` 的 `status` 输出（05-01 产出）
    - `.planning/phases/05-windows-service-reliability/05-VALIDATION.md` 的 Manual-Only 表
  </read_first>
  <action>
    新建 `packaging/windows/verify-service.ps1`（`#requires -RunAsAdministrator`），依次执行并断言：
    1. `install`：调用同目录 `install.ps1`；断言 `Get-Service LiuZXSKFService` 存在且状态为 `Running`。
    2. `status`：运行 `skf-service.exe status`；断言输出包含 `Running` 与 `stage=serve`。
    3. **覆盖升级**：在服务运行中再次运行 `install.ps1`；断言退出码 0、服务仍 `Running`、`status` 仍 `stage=serve`。
    4. **ACL**：`icacls $InstallDir`；断言 `Users` 行不含 `(F)`/`(M)`/`(W)`。
    5. `uninstall`：调用 `uninstall.ps1`；断言 `Get-Service` 找不到该服务且 `$InstallDir` 不存在。
    6. **reinstall**：再次 `install.ps1` 并断言 `Running`。
    7. 最终 `uninstall.ps1` 清理。
    每步失败即 `throw`，成功打印 `PASS: <step>`；脚本末尾打印 `ALL CHECKS PASSED`。
    另外提供 `-KeepInstalled` 开关以便人工保留安装以观察 `sc query` 的 StartPending。
  </action>
  <acceptance_criteria>
    - `test -f packaging/windows/verify-service.ps1` 为真
    - `grep -c 'RunAsAdministrator' packaging/windows/verify-service.ps1` 输出 `1`
    - `grep -c 'PASS:' packaging/windows/verify-service.ps1` 输出 `>= 5`
    - `grep -c 'ALL CHECKS PASSED' packaging/windows/verify-service.ps1` 输出 `1`
    - `grep -c 'icacls' packaging/windows/verify-service.ps1` 输出 `>= 1`
    - `grep -c 'install.ps1' packaging/windows/verify-service.ps1` 输出 `>= 2`
  </acceptance_criteria>
  <verify>`test -f packaging/windows/verify-service.ps1 && grep -c 'PASS:' packaging/windows/verify-service.ps1`</verify>
</task>
