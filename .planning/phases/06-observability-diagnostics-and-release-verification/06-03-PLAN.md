<task id="06-03-02" type="execute">
  <name>release workflow 校验 checksum 与解包内容</name>
  <files>.github/workflows/release-windows.yml</files>
  <read_first>
    - `.github/workflows/release-windows.yml` 全文

    - `.planning/phases/06-observability-diagnostics-and-release-verification/06-CONTEXT.md` — D-14
  </read_first>
  <action>
    在 "Verify release asset" 步骤之后、上传之前插入：
    ```yaml
      - name: Verify checksum
        shell: powershell
        run: |
          $zip = ".\dist\skf-service-windows-x64-gm3000-x86.zip"
          $sum = "$zip.sha256"
          if (-not (Test-Path $sum)) { throw "checksum file missing: $sum" }
          $expected = (Get-Content $sum).Split(' ')[0].Trim()
          $actual = (Get-FileHash -Algorithm SHA256 -Path $zip).Hash.ToLower()
          if ($expected -ne $actual) { throw "checksum mismatch: expected $expected got $actual" }

      - name: Verify extracted package contents and architecture
        shell: powershell
        run: |
          $zip = ".\dist\skf-service-windows-x64-gm3000-x86.zip"
          $out = ".\dist\_verify"
          if (Test-Path $out) { Remove-Item $out -Recurse -Force }
          Expand-Archive -Path $zip -DestinationPath $out -Force
          foreach ($required in @("skf-service.exe","native\GM3000\windows\mtoken_gm3000.dll","config\skf.yaml","api")) {
            if (-not (Test-Path (Join-Path $out $required))) { throw "package is missing $required" }
          }
          function Get-PeMachine([string]$Path) {
            $fs = [IO.File]::OpenRead($Path); try {
              $br = New-Object IO.BinaryReader($fs)
              $fs.Seek(0x3C, 'Begin') | Out-Null
              $pe = $br.ReadInt32()
              $fs.Seek($pe + 4, 'Begin') | Out-Null
              return $br.ReadUInt16()
            } finally { $fs.Dispose() }
          }
          foreach ($pe in @("skf-service.exe","native\GM3000\windows\mtoken_gm3000.dll")) {
            $m = Get-PeMachine (Join-Path $out $pe)
            if ($m -ne 0x014C) { throw "$pe is not PE32/i386: 0x{0:X4}" -f $m }
          }
    ```
    并把 upload-artifact 与 `gh release create` 增加 `.sha256` 文件作为第二个路径/附件。
  </action>

  <action>
    新建 `RELEASE-NOTES.md`：
    - **标题与版本**：`v0.3.0 — production hardening`。
    - **Intentional behavior changes**（每项：变更、原因、迁移路径）：
      1. 不透明句柄：`ConnectDev` 返回 `dev-N` 等，客户端回传指针十进制/整数被拒（`-11`）。迁移：使用服务返回的句柄字符串；`DisConnectDev` 传整数会得到 `-11`（此前会传给厂商库）。
      2. 默认拒绝非回环绑定：需 `allow_remote: true` 或 `SKF_ALLOW_REMOTE=1`。
      3. 帧 1 MiB / 载荷 256 KiB / 连接 64 / 非 wait 请求 30s 超时。
      4. 服务启动失败以分类非零码退出（`1..4`）并写 `service-state.json`。
      5. provider 边界：配置无效致命；库文件缺失降级为 `Load Lib Failed` 运行时错误。
      6. 新增 `apiVersion` 字段接受与 `GetProtocolVersion`（增补，不影响旧客户端）。
      7. `IssueCertificate`/`Transmit` 可通过 `SKF_RESTRICT_LEGACY=1` 限制（默认可用）。
    - **New capabilities**：`diagnose`、结构化轮转日志、安装目录 ACL、checksum、`OperationClass` 文档。
    - **Compatibility statement**：v0.2.0 客户端无需修改；37 个 v0.2.0 夹具仍匹配。
    - **Notes**：日志实现为仓库内实现（未引入 flexi_logger），原因见 06-01 SUMMARY。
  </action>
