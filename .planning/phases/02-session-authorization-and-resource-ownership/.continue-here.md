# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each was discovered through an actual failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: The compiler does not catch dead or degraded code left behind by a scripted edit — this wave produced a `match` with a single wildcard arm and an error helper returning `id: None` (the M-04 anti-pattern already fixed once), and `cargo check` reported **0 errors and 0 warnings** — structural mitigation: read `git diff` hunk by hunk after any scripted multi-site edit; never treat a clean compile as evidence of a correct edit
- [ ] CONSTRAINT: A large simultaneous drift may be a transient, not a regression — 24 device-dependent methods appeared to break at once at the start of wave 4; the token was attached throughout, and the pre-Phase-2 binary built in a worktree reproduced the same result, proving the cause was a window where the middleware reported no devices right after a service was killed — structural mitigation: on a mass drift, reproduce with the pre-change binary in a `git worktree` before touching code, and check `system_profiler SPUSBDataType` for the token
- [ ] CONSTRAINT: Bare greps still lie about this codebase — `grep -c 'hash_' src/main.rs` returned 23, but every match was a local variable in an out-of-scope branch; the property actually held — structural mitigation: before believing a grep failure, print the matching lines; prefer comment-aware invariant tests (`tests/session_invariants.rs`, `tests/provider_invariants.rs`) as the authoritative check

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns (do NOT repeat these)

- [MASS DRIFT TREATED AS A REGRESSION]: reproduce with the pre-change binary in a worktree first; the device may simply be unavailable for a moment
- [CLEAN COMPILE AS EVIDENCE]: a scripted rewrite left dead code the compiler accepted → read the diff per hunk
- [BARE GREP AS EVIDENCE]: print matching lines before acting on a grep result
- [HIDING A CONTRACT CHANGE]: record it in the README and provenance; never widen `normalize`
- [SMUGGLING BEHAVIOUR CHANGES INTO A MOVE]: each migrated branch is verified by its own fixture; genuine fixes (fewer `into_raw` leaks, no per-call library load) are listed explicitly rather than left implicit
- [INTERIOR MUTABILITY IN SESSION STATE]: the session reaches its state through `&mut self`; only the registry locks
