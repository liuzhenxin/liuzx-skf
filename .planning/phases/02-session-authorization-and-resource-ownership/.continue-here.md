<decisions_made>

- Session state is held **by value**, never behind an `Arc` (an `Arc` would not be `Send` because of `Box<dyn DeviceGuard>`, and fixing that needs a forbidden `unsafe impl Sync`)
- The registry stores `Weak<SessionMarker>` and exposes only `register`/`deregister`/`session_count` — no lookup, no cross-session mutation
- Per-operation PIN re-verification is removed by design; the TTL-bounded session grant is the authorization
- Device loss is detected on next use by the session that observes it, which keeps session state lock-free
- `SKF_AUTH_TTL_SECONDS` (default 600) is the only TTL channel; it must never become a YAML key, because `SkfConfig`'s flattened provider map would fail to parse an extra top-level key
