# Plan 02-02: Per-Session Authorization with Expiry

<objective>
把授权从进程级 `SkfContext.pins` 搬到会话上：授权以 `(provider, device, app) -> expires_at` 表示，TTL 来自环境变量，授权在断连、超时、设备不可用三种情况下失效，且**不保留任何可恢复的 PIN 副本**。

本计划完成后，SESS-02 的对抗性测试（两会话）必须通过——这是本阶段的核心验收。
</objective>

<threat_model>
**ASVS Level:** 1 · **Block on:** high

| ID | Threat | Severity | Mitigation in this plan |
|----|--------|----------|-------------------------|
| T-02-03 | 授权状态经进程级结构泄漏到其他会话 → 任一连接验证过的 PIN 对所有连接生效 | HIGH | 授权表是 `SessionState` 的字段，只由该会话的 `&mut` 访问；测试用两个真实会话证明 A 的授权不使 B 通过 |
| T-02-04 | 授权条目保留可恢复的 PIN → 凭据暴露（当前 `pins` 正是明文存储） | HIGH | 条目**只有** `expires_at: Instant`，结构体不含字符串字段；验收标准以 grep 断言该结构体内无 `String`/`pin` |
| T-02-10 | TTL 被写入 `config/skf.yaml`，因 `#[serde(flatten)]` 导致整份配置解析失败 | HIGH | TTL **只**从 `SKF_AUTH_TTL_SECONDS` 读取；验收标准断言两份 YAML 仍可解析且 `SkfConfig` 无新字段 |
| T-02-11 | 授权过期只做"判定"而不移除条目，使残留条目在会话结束后仍可达 | MEDIUM | 过期判定在检查时移出条目；`Drop` 随会话整体消失 |

**Security constraint:** 本计划必须在迁移 `CheckPIN` 行为时保留其**响应契约**（无 PIN 的会话调用需授权方法时返回既有错误码），且不得把 PIN 写入任何日志、错误消息或结构体字段。
</threat_model>

<must_haves>
- 授权条目结构体内**不含**任何 `String` 或 PIN 字段
- 两个并发会话中，A 验证 PIN 不会使 B 的敏感操作通过（对抗性测试）
- 超过 TTL 后授权失效
- 断连后授权不可用
- `SKF_AUTH_TTL_SECONDS` 生效；无效值回落默认并记录警告；两份 YAML 结构与解析不变
- `grep -c 'ctx\.pins' src/main.rs` 输出 0
</must_haves>

    2. 创建 `src/session/auth.rs`：
       ```rust
       /// Why an authorization check failed.
       #[derive(Debug, Clone, Copy, PartialEq, Eq)]
       pub enum AuthRejection {
           NotAuthorized,
           Expired,
           DeviceUnavailable,
       }

       /// Identifies what was authorized. Deliberately contains no credential.
       #[derive(Debug, Clone, PartialEq, Eq, Hash)]
       pub struct AuthKey {
           pub provider: String,
           pub device: String,
           pub application: String,
       }

       /// One authorization grant.
       ///
       /// Holds **only** a deadline. The PIN that produced it is never stored
       /// (SESS-05): keeping it would make this struct a credential store, and
       /// zeroizing a `String` cannot be done reliably (PITFALLS Pitfall 6).
       #[derive(Debug, Clone, Copy, PartialEq, Eq)]
       pub struct Grant {
           pub expires_at: std::time::Instant,
       }

       /// Default authorization lifetime when SKF_AUTH_TTL_SECONDS is unset.
       pub const DEFAULT_TTL_SECONDS: u64 = 600;

       /// Read the TTL from the environment, falling back to the default.
       ///
       /// `0` is treated as invalid rather than "never expires": SESS-03 requires
       /// expiry, so an infinite grant is not representable (D-08).
       pub fn ttl_from_env() -> std::time::Duration { /* parse, warn on invalid/0 */ }

       /// Per-session authorization grants.
       #[derive(Debug, Default)]
       pub struct AuthTable {
           grants: std::collections::HashMap<AuthKey, Grant>,
           ttl: std::time::Duration,
       }

       impl AuthTable {
           pub fn new(ttl: std::time::Duration) -> Self
           /// Record a successful verification.
           pub fn grant(&mut self, key: AuthKey)
           /// Check without consuming; expired entries are removed and reported.
           pub fn check(&mut self, key: &AuthKey) -> Result<(), AuthRejection>
           /// Drop every grant for one device (used when the device disappears).
           pub fn invalidate_device(&mut self, provider: &str, device: &str) -> usize
           pub fn len(&self) -> usize
           pub fn is_empty(&self) -> bool
       }
       ```
       `check` 必须在判定过期时**移除**条目（T-02-11），不要只返回 `Expired` 而留下条目。
    3. 在 `SessionState` 增加字段 `auth: AuthTable`，并在 `SessionState::new(ttl)` 中初始化（`SessionState::new` 需要 TTL 参数）。
    4. 在 `src/session/auth.rs` 添加 `#[cfg(test)] mod tests`，覆盖：
       - 授权后 `check` 通过
       - 未授权的 key 返回 `NotAuthorized`
       - TTL 为 50ms 时，`std::thread::sleep(80ms)` 后返回 `Expired`，且 `len()` 归零（条目被移除）
       - `invalidate_device` 只清除匹配 `(provider, device)` 的条目，其他设备不受影响，返回被清除的数量
       - `AuthTable` 无 `String` 值字段：以 `std::mem::size_of::<Grant>()` 断言其为 `Instant` 的大小（`Grant` 是 `Copy` 且不含堆分配）
       - `ttl_from_env` 在未设置时返回 `DEFAULT_TTL_SECONDS`
  </action>

       在 `SessionState` 上增加方法：
       ```rust
       /// Clear authorization for one device after an operation found it missing.
       ///
       /// Called by the session that observed the failure, using its own `&mut`
       /// access. The registry is deliberately not involved: a cross-session
       /// mutator would require interior mutability here and would turn the
       /// registry into the shared-state defect this phase removes.
       pub fn invalidate_device(&mut self, provider: &str, device: &str) -> usize
       ```
       并补充文档说明：**失效是"下次使用时发现"，不是实时**；这是 D-09 明确选择的取舍，实时广播留待有需求时再做。
    3. 在 `src/main.rs` 的 `session_authorized` 辅助中接入：授权检查失败且 provider 报告设备不可用时（判据为 `ProviderError::Injected(SkfError::DeviceRemoved)` 或"设备不存在"类原生码），调用 `state.invalidate_device(provider, device)` 并返回 `AuthRejection::DeviceUnavailable`。
