## Security posture

- Default is unchanged: plaintext loopback; TLS and client authentication are
  opt-in.
- Remote exposure requires opt-in **and** TLS **and** client authentication, decided
  before the socket is opened.
- Secrets (private key, bearer token) never reach logs, `diagnose`, the status file,
  or release metadata; a source-scan test enforces log redaction and the audit event
  type cannot carry a secret.
