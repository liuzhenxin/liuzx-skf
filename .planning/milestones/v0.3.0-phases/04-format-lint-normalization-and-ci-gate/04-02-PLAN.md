<task id="04-02-02" type="execute">
  <name>修复机械类 lint（get_first / needless_return / needless_borrows / single_match / bool_assert / for_kv_map / collapsible_str_replace）</name>
  <files>src/main.rs, src/domain/container.rs, src/protocol/params.rs, src/domain/*.rs, tests/transport_limits.rs</files>
  <read_first>
    - `src/main.rs`（25 处 `req.params.get(0)` 的上下文；多数在未迁移分支）
    - `src/domain/container.rs` 的 `decode_certificate`（`collapsible_str_replace`）
    - `src/protocol/params.rs` 的 `optional_accessors_fall_back`（`bool_assert_comparison`）
    - `tests/transport_limits.rs` 的 `an_over_limit_frame_is_rejected_and_the_service_survives`（`single_match`）
    - `.planning/phases/04-format-lint-normalization-and-ci-gate/04-CONTEXT.md` — D-04
  </read_first>
  <action>
    逐类做等价改写，每完成一类运行一次 `cargo test --lib`：
    1. `clippy::get_first`（25）：`req.params.get(0)` → `req.params.first()`。仅当索引确为 0；不要改动 `get(1)` 等。
    2. `clippy::needless_return`（12）：删除处于块尾的 `return`（保留 `return` 作为早返回的表达）。注意 match 分支内 `return` 是否在块尾。
    3. `clippy::needless_borrows_for_generic_args`（9）：按 clippy 建议移除多余 `&`；逐处确认调用目标确实接受按值参数（如 `format!`/`push_str`/`Vec::push`）。
    4. `clippy::single_match`（`tests/transport_limits.rs`）：把 `match outcome { Ok(Some(Ok(Message::Text(text)))) => panic!(...), _ => {} }` 改为 `if let Some(Ok(Message::Text(text))) = outcome { panic!(...) }`。
    5. `clippy::bool_assert_comparison`（`src/protocol/params.rs`）：`assert_eq!(p.optional_bool(0, true), true)` → `assert!(p.optional_bool(0, true))`。
    6. `clippy::for_kv_map`：按 clippy 指示改用 `.values()`（或 `.keys()`），不改变遍历语义。
    7. `clippy::collapsible_str_replace`（`src/domain/container.rs::decode_certificate`）：`.replace('\n', "").replace('\r', "")` → `.replace(['\n', '\r'], "")`。
    8. 全部完成后运行 `cargo clippy --all-targets 2>&1 | grep -c '^warning: '`，期望从 63 降到 7 以下（剩余 await_holding_lock×4、too_many_arguments×2、missing_safety_doc×1）。
  </action>
  <acceptance_criteria>
    - `cargo clippy --all-targets 2>&1 | grep -c 'get_first'` 输出 `0`
    - `cargo clippy --all-targets 2>&1 | grep -c 'needless_return'` 输出 `0`
    - `cargo clippy --all-targets 2>&1 | grep -c 'needless_borrows_for_generic_args'` 输出 `0`
    - `cargo clippy --all-targets 2>&1 | grep -c 'single_match\|bool_assert_comparison\|for_kv_map\|collapsible_str_replace'` 输出 `0`
    - `cargo test` 退出码 0
    - `cargo test --test contract_fixtures` 退出码 0（37/37）
  </acceptance_criteria>
  <verify>`cargo clippy --all-targets 2>&1 | grep -cE 'get_first|needless_return|needless_borrows|single_match|bool_assert|for_kv_map|collapsible'`</verify>

<task id="04-02-03" type="execute">
  <name>修复真实隐患并加 scoped allow（await_holding_lock / missing_safety_doc / too_many_arguments）</name>
  <files>tests/loopback_gate.rs, src/skf/api.rs</files>
  <read_first>
    - `tests/loopback_gate.rs` 全文（`env_lock()` 与四个 async 测试）
    - `src/skf/api.rs` 的 `get_func` 与其 `unsafe` 语义；`encrypt_data`/`decrypt_data` 的参数与 SKF C ABI
    - `.planning/phases/04-format-lint-normalization-and-ci-gate/04-CONTEXT.md` — D-04
  </read_first>
  <action>
    1. `tests/loopback_gate.rs`：把进程级 env 串行锁从 `std::sync::Mutex` 改为 `tokio::sync::Mutex`：
       ```rust
       fn env_lock() -> &'static tokio::sync::Mutex<()> {
           static LOCK: tokio::sync::Mutex<()> = tokio::sync::Mutex::const_new(());
           &LOCK
       }
       ```
       并把每个测试开头的 `let _guard = env_lock();` 改为 `let _guard = env_lock().lock().await;`。这消除"持 std 锁跨 await"，且是 async 上下文中的正确做法。
    2. `src/skf/api.rs::get_func`：补 `# Safety` 文档段，说明调用者必须保证返回的函数指针以正确的签名调用（从厂商库加载的符号，签名由调用点负责）。
    3. `src/skf/api.rs::encrypt_data` / `decrypt_data`：各加
       ```rust
       // Mirrors the SKF_EncryptData / SKF_DecryptData C ABI signature; grouping the
       // arguments would break the one-to-one correspondence with the vendor API.
       #[allow(clippy::too_many_arguments)]
       ```
       保持参数列表不变。
    4. 运行 `cargo clippy --all-targets -- -D warnings`，确认退出 0。
  </action>
  <acceptance_criteria>
    - `grep -c 'tokio::sync::Mutex' tests/loopback_gate.rs` 输出 `>= 1`
    - `grep -c 'std::sync::Mutex' tests/loopback_gate.rs` 输出 `0`
    - `grep -c 'lock().await' tests/loopback_gate.rs` 输出 `>= 4`
    - `grep -c '# Safety' src/skf/api.rs` 输出 `>= 1`
    - `grep -c 'allow(clippy::too_many_arguments)' src/skf/api.rs` 输出 `2`
    - `cargo clippy --all-targets -- -D warnings` 退出码 0
    - `cargo test --test loopback_gate` 退出码 0
  </acceptance_criteria>
  <verify>`cargo clippy --all-targets -- -D warnings && cargo test --test loopback_gate`</verify>
</task>
