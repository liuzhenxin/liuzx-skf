# Plan 04-01: Repository-Wide Formatting Baseline

<objective>
让 `cargo fmt --all -- --check` 在全仓储通过，并把这次变更作为**唯一一个 formatting-only 提交**落地，使 `git blame` 与 review 能把格式化与逻辑变更分开（QUAL-01，D-01..D-03）。

</objective>
