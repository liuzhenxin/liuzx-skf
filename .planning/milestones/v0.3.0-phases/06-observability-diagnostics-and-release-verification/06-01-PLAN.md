# Plan 06-01: Structured, Rotating Logs and Redaction

<objective>
让服务日志结构化（JSON Lines）、分级、按 10 MiB 轮转并保留 7 个文件，并用运行时 `sanitize` + 源码扫描测试保证日志不含 PIN、私钥、会话密钥或解密载荷（OBS-01/02）。

**相对 CONTEXT D-01 的强制偏差：** D-01 选择 `flexi_logger`，但本机 registry 不可达（`cargo add flexi_logger --dry-run` 超时），新增依赖会破坏构建。因此本计划用 **仓库内实现**（`log` + `serde_json`，均为既有依赖）完成同样的"结构化 + 轮转 + 有界保留"。功能不变，仅机制不同。此偏差必须写入 SUMMARY 与 `RELEASE-NOTES.md` 的工具说明。
</objective>

<threat_model>
**ASVS Level:** 1 · **Block on:** high

| ID | Threat | Severity | Mitigation in this plan |
|----|--------|----------|-------------------------|
| T-06-01 | 日志泄露 PIN / 私钥 / 会话密钥 / 解密载荷 | HIGH | 不记录请求参数；`sanitize` 处理外部值；源码扫描测试阻止未来在日志宏中直接引用敏感标识符 |
| T-06-02 | 日志无界增长填满磁盘 | MEDIUM | 10 MiB 轮转 + 保留 7 个文件；轮转逻辑单测 |
| T-06-03 | 服务与结构化日志写同一文件导致交错/损坏 | MEDIUM | stdout 重定向改到独立的 `skf-service.console.log` |
| T-06-04 | JSON 行注入（换行/控制字符）破坏日志解析 | MEDIUM | `serde_json` 转义 message；`sanitize` 去控制字符 |
</threat_model>

<must_haves>
- `src/logging.rs` 提供 `RotatingFileLogger`（`log::Log`）、`init_console`、`init_service_file`、`sanitize`、`MAX_LOG_BYTES=10MiB`、`KEEP_LOG_FILES=7`
- 每条日志为一行 JSON：`ts`（epoch 秒）、`level`、`target`、`message`
- 超过 `MAX_LOG_BYTES` 时轮转 `.log`→`.1`→`.2`…，文件总数不超过 `KEEP_LOG_FILES+1`
- `win_service` 用 `logging::init_service_file` 初始化，stdout 重定向到 `skf-service.console.log`
- `tests/log_redaction.rs` 扫描源码，日志宏中出现敏感标识符即失败，除非带 `// redaction-allow:`
- `cargo test`、37/37 契约、fmt/clippy/i686 全部通过
</must_haves>

    细节：
    - JSON 行用 `serde_json::json!({"ts": epoch_secs, "level": record.level().as_str(), "target": record.target(), "message": record.args().to_string()})` 然后 `serde_json::to_string` → 单行（`to_string` 不含换行）。
    - 轮转：先把 `path` rename 到 `.1`（若存在则先删 `.1` 或整体右移），再右移 `.1→.2` … `.keep-1→.keep`，删除 `.keep`。随后以 append 重新打开 `path`，`written=0`。
    - `enabled` 用 `log::max_level()`；`level_from_env()` 解析 `RUST_LOG` 中的 trace/debug/info/warn/error（大小写不敏感），默认 `Info`。
    - `timestamp_secs()` 返回 `SystemTime` 的 epoch 秒字符串。
    在 `src/lib.rs` 增加 `pub mod logging;`。
    增加 `#[cfg(test)] mod tests`：
    - `json_line_has_expected_fields`：构造 logger 到临时目录，`log::Log::log` 一条记录，读取文件首行 `serde_json::from_str` 后断言含 `ts`/`level`/`target`/`message`；
    - `rotation_creates_numbered_files_and_bounds_retention`：`max_bytes` 设小（如 200），写多条触发多次轮转，断言存在 `skf-service.log` 与 `.1`，且文件总数 `<= keep+1`；
    - `sanitize_removes_control_chars_and_truncates`：传入含 `\n`/`\0` 与超长字符串，断言无控制字符且长度 `<=512`；
    - `message_with_newline_stays_one_line`：message 含 `\n`，断言日志文件行数等于写入次数。
