# Plan 08-03: Bind Coupling and Hermetic Client-Authentication Tests

<objective>
落实 AUTH-03（非回环绑定必须启用客户端认证），并用 hermetic 证书/令牌端到端证明 AUTH-01/02/04：有效通过、缺失拒绝、无效拒绝，且令牌与客户端证书从不进入日志或诊断。

    1. `bind_with_progress` 在现有 `allow_remote` 检查之后追加：
       ```rust
       let mode = crate::client_auth::ClientAuthMode::parse(&config.tls_client_auth())
           .map_err(StartupError::Config)?;
       if !ws_socket.ip().is_loopback() && mode.requires_loopback() {
           return Err(StartupError::Bind(format!(
               "refusing to bind WebSocket listener to non-loopback address {} without client authentication; set tls.client_auth to mtls or token",
               ws_socket
           )));

       ```

       - 新增 `loopback_without_client_auth_still_binds`：`127.0.0.1:0` 且无 `tls` 仍成功。

<task id="08-03-02" type="execute">
  <name>mTLS 与 token 端到端测试</name>
  <files>tests/client_auth.rs</files>
  <read_first>
    - `tests/tls.rs`（rcgen 材料生成、TLS 客户端、启动辅助）
    - `tests/session_support/mod.rs`
    - `.planning/phases/08-client-authentication/08-RESEARCH.md`（rcgen CA 签发、Bearer 头）
  </read_first>
  <action>
    1. 新建 `tests/client_auth.rs`，复用 `tests/tls.rs` 中的启动/证书工具（抽成 `tests/session_support` 或本地复制；优先抽取到 `session_support` 避免重复）。
    2. 材料：
       - 服务器自签证书（`localhost`）。
       - client CA（`IsCa::Ca(BasicConstraints::Unconstrained)`）+ 由该 CA 签发的客户端证书，CN=`test-client`。
    3. 测试：
       - `mtls_without_client_certificate_is_refused`：服务器 `client_auth: mtls` + `client_ca_file`；客户端不带证书 → 握手失败。
       - `mtls_with_valid_client_certificate_works`：客户端带 CA 签发的证书 → `SetLanguage` 返回 `error: 0`。
       - `mtls_with_untrusted_client_certificate_is_refused`：客户端证书由**另一个** CA 签发 → 握手失败。
       - `token_is_required_and_checked`：服务器 `client_auth: token`、`SKF_TLS_TOKEN=secret`；无头 → 拒绝；错误令牌 → 拒绝；`Authorization: Bearer secret` → `error: 0`。
       - `token_mode_works_without_tls_on_loopback`：无 `tls:` 证书，仅 token → 明文 + 令牌可工作（loopback 允许）。
    4. Bearer 头：`let mut req = format!("ws://127.0.0.1:{}/", port).into_client_request()?; req.headers_mut().insert("Authorization", HeaderValue::from_static("Bearer secret")); tokio_tungstenite::client_async(req, stream)`。
    5. 不签入私钥；不依赖 OpenSSL CLI。
  </action>
  <acceptance_criteria>
    - `test -f tests/client_auth.rs` 为真
    - `grep -c 'fn mtls_without_client_certificate_is_refused\|fn mtls_with_valid_client_certificate_works\|fn mtls_with_untrusted_client_certificate_is_refused\|fn token_is_required_and_checked\|fn token_mode_works_without_tls_on_loopback' tests/client_auth.rs` 输出 `5`
    - `cargo test --test client_auth` 退出码 0
  </acceptance_criteria>
  <verify>`cargo test --test client_auth`</verify>
</task>
